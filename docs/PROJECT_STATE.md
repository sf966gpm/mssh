# Состояние проекта MSSH

Обновлено: 2026-10-20

## Сейчас

- MSSH разрабатывается заново на Go и Fyne; старая реализация не используется.
- Go-модуль находится в `app/`. Архитектура простая, без DI.
- Запуск приложения: `app/cmd/mssh/`; интерфейс: `app/internal/ui/`.
- Окно фиксированного размера `1200×800`, разделено на панели 50/50.
- Левая панель открывает `~/.ssh` (если каталога нет — домашнюю папку), показывает в том числе скрытые файлы и позволяет переходить по каталогам.
- Правая панель открывает UTF-8 текстовые файлы размером до 2 МиБ. Изменения сохраняются кнопкой; при уходе с несохранённым текстом показывается подтверждение.

## Сборка и запуск

Из корня репозитория:

```sh
make -C app build
make -C app run
```

Бинарник сборки: `app/bin/mssh`.
